# UNSW-NB15 — partition train/test

Cette copie contient la partition d'entraînement et de test du dataset UNSW-NB15 :

- `UNSW_NB15_training-set.csv` — 175 341 enregistrements ;
- `UNSW_NB15_testing-set.csv` — 82 332 enregistrements.

Le dataset a été créé par l'UNSW Canberra / Australian Centre for Cyber Security pour la recherche en détection d'intrusion. Les fichiers sont inclus ici pour la validation expérimentale de ce dépôt.

Source officielle et informations de citation : https://research.unsw.edu.au/projects/unsw-nb15-dataset
