# UNSW-NB15 — partitions train/test et version complète

Ce dossier contient deux formats de travail :

- `UNSW-NB15-train-test.zip` : archive compacte des partitions d'entraînement et de test ;
- `UNSW_NB15_training-set.csv` et `UNSW_NB15_testing-set.csv` : mêmes partitions non compressées ;
- `UNSW-NB15_1.csv` à `UNSW-NB15_4.csv` : version complète, totalisant 2 540 044 enregistrements ;
- les fichiers de métadonnées disponibles (`UNSW_NB15_features.csv`, ground truth et événements) lorsqu'ils sont fournis par l'archive.

Source et informations de citation :
https://research.unsw.edu.au/projects/unsw-nb15-dataset

Le dataset UNSW-NB15 est destiné à la recherche académique. Respecter les conditions d'utilisation et citer les travaux des auteurs indiqués sur la page officielle.
